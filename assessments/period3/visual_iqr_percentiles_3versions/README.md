# Statistics 10 - Visual IQR / Boxplot Evaluation (3 Versions)

Print-ready Period III assessment package created from the current IQR / modified-boxplot and percentile sequence.

## Design

Each version is equivalent in structure and difficulty but uses different datasets and graph situations.

- Section I - Read the graph (30): compare two modified boxplots on the same scale using median, IQR, regular spread and outlier evidence.
- Section II - Construct an IQR / modified boxplot (35): order raw data, find Q1/Q2/Q3, calculate IQR, 1.5-IQR fences, classify outliers, identify real whisker endpoints and construct the modified boxplot on a supplied scale.
- Section III - Understand boxplot behavior (15): compare two datasets whose central 50% is unchanged while one extreme observation becomes an outlier.
- Section IV - Percentiles and deciles (20): P40, P65, D7 and interpretation of percentile rank.

## Statistical conventions

- IQR / boxplots: median-of-halves convention. For odd n, exclude the overall median before finding Q1 and Q3.
- Fences classify outliers; fences are not whisker endpoints.
- Whiskers stop at the most extreme real non-outlier observations.
- Percentiles / deciles: L=(k/100)(n+1), with interpolation for decimal locators.

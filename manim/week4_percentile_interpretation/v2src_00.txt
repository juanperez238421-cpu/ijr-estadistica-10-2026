"""Statistics 10 · Period 1 · Week 4 — Percentile Interpretation.

Senior classroom edition. Direct continuation of Week 3 Deciles & Percentiles.

Week 3 answered:  WHERE is P_k and what value does it have?
Week 4 answers:  WHAT DOES that percentile statement mean in context?

Interpretation route used throughout:
1. READ
2. IDENTIFY k
3. IDENTIFY VALUE
4. BELOW / AT
5. ABOVE
6. CONTEXT
7. CHECK CLAIM
8. COMMUNICATE

Core classroom statement:
    If P_k = x, then approximately k% of the ordered observations are at or
    below x, and approximately (100-k)% are above x.

This complementary wording avoids counting the cutoff value on both sides.
With tied values, exact counts may differ slightly; this is why the lesson
uses the word "approximately".

Important qualification:
- Percentiles describe relative position in an ordered distribution.
- A percentile number is not a percent of the raw value.
- When context changes, "higher percentile" does not automatically mean
  "better" performance (for example, race time where lower is better).
- Comparing percentile ranks across different groups/tests describes relative
  standing, not necessarily a larger raw score.

@dataclass(frozen=True)
class PercentileStatement:
    k: int
    value: float
    context: str
    unit: str = ""

    @property
    def above(self) -> int:
        return 100 - self.k


def fmt(v: float) -> str:
    if abs(v - round(v)) < 1e-9:
        return str(int(round(v)))
    return f"{v:.2f}".rstrip("0").rstrip(".")
